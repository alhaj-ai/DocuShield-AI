# Security Policy

## Supported Versions
Security updates are applied to the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
If you discover a security vulnerability or PII detection bypass, please do NOT file a public issue.
Instead, email **`ai.mohammed.alhaj@gmail.com`** directly. We will review and patch vulnerabilities promptly.
